# Product Catalog Service

This service manages product information for the Online Boutique application.

## Product Data

The `products.json` file contains product names, descriptions, image paths, prices, and categories.

## Technology

- Go
- JSON
- gRPC

## Reference

Based on the [GoogleCloudPlatform microservices-demo](https://github.com/GoogleCloudPlatform/microservices-demo) project.
