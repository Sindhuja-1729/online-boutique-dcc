# Online Boutique – Distributed & Cloud Computing

A cloud-native e-commerce application using microservices, gRPC, Kubernetes and distributed computing.

## Project Overview

This project is based on Google's Online Boutique microservices demo.

### Architecture
- Microservices Architecture
- gRPC and HTTP Communication
- Distributed and Cloud Computing
- Kubernetes for Container Orchestration
- Redis for Data Storage
